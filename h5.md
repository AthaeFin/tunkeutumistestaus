## x) tiivistä

Karvinen 2023: Find Hidden Web Directories - Fuzz URLs with ffuf

- Ffuf on fuzzer, joka etsii piilotettuja hakemistoja, lähteen mukaan mitä vaan (löytyisiköhän sen avulla kadoksissa ollut motivaatio)
- Ffuf asennetaan ihan perus sudo apt-get install ffuf, lähtee käyntiin ./ffuf
- Tarvitsee harjoittelumaalin, sellaisen saa täältä: https://terokarvinen.com/2023/fuzz-urls-find-hidden-directories/dirfuzt-0

Hoikkala 2023: ffuf README.md

- Motivaatiota ei mainittu asioista, mitä ffuf:illa voi löytää, ellei ne ole evästeissä piilossa. Muita löydettäviä asioita hakemistojen lisäksi http status-koodeja, sertifikaatteja ja avaimia, POST json dataa.
- Hakutuloksia tulee paljon, niitä kannattaa suodattaa.

## b) Fuff me. Asenna FuffMe-harjoitusmaali. Karvinen 2023: Fuffme - Install Web Fuzzing Target on Debian

Tässä kohtaa tapahtuu maaginen koneen vaihto, luulen että romuläppäri menee solmuun jos pitää kontteja pistää pyörimään virtuaalikoneessa (ja keittiön valo sattuu ikävästi silmiin neljältä aamuyöstä, nörttinurkassa on pehmeä valo ja vihaisempaa musiikkia.). Pistin uuden debian-virtuaalikoneen pystyyn, koska en muistanut edellisen salasanaa. 

Kaikki meni ihan putkeen ilman ongelmia, kunnes piti ffufferilla löytää jotain :) tämän kanssa tapellut nyt 2h tuloksetta. Mitä olen kokeillut:

- kirjoitusvirheiden syynäys -> ei ole kirjoitusvirheitä
- docker meni kumoon, ei suostu käynnistymään uudelleen
- olen väärässä hakemistossa -> olen kokeillut kaikki hakemistot ja niiden mummotkin
- väärä portti -> ihan tuttu turvallinen 80
- väärä url -> kokeiltu localhost, 0.0.0.0 (mikä manuaalissa jossain kohtaa luki), 127.0.0.1 loopback-osoite
- repiä hiukset päästä -> ei auttanut
- vanha kunnon "ootko koittanu käynnistää uudelleen" -> olen
- kaikki sanakirjat, kontit jne on ladattu, ongelmat alkoi kun otin vehkeen pois netistä.

- toisen virtuaalikoneen uudelleenboottauksen ja kontin uudelleenkäynnistyksen jälkeen localhost toimii curlilla, pelottaa mitä käy kun otan virtuaalicatkaapelin pois seinästä: näköjään localhost toimii. TOISINSANOEN "ootko koittanu käynnistää uudelleen" on ihan validi ongelmanratkaisukeino.

tästä puoli tuntia eteenpäin, niin sain tämän aikaiseksi:
