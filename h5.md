# h5 - Fuzzy

## x) tiivistä

Karvinen 2023: Find Hidden Web Directories - Fuzz URLs with ffuf

- Ffuf on fuzzer, joka etsii piilotettuja hakemistoja, lähteen mukaan mitä vaan (löytyisiköhän sen avulla kadoksissa ollut motivaatio)
- Ffuf asennetaan ihan perus sudo apt-get install ffuf, lähtee käyntiin ./ffuf
- Tarvitsee harjoittelumaalin, sellaisen saa täältä: https://terokarvinen.com/2023/fuzz-urls-find-hidden-directories/dirfuzt-0

Hoikkala 2023: ffuf README.md

- Motivaatiota ei mainittu asioista, mitä ffuf:illa voi löytää, ellei ne ole evästeissä piilossa. Muita löydettäviä asioita hakemistojen lisäksi http status-koodeja, sertifikaatteja ja avaimia, POST json dataa.
- Hakutuloksia tulee paljon, niitä kannattaa suodattaa.

## a) Fuzzzz. Ratkaise dirfuzt-1 artikkelista Karvinen 2023: Find Hidden Web Directories - Fuzz URLs with ffuf.

Tein aluksi dirfuzt-0 jotta pääsin jyvälle miten ffuf toimii. Latasin sanalistan, ffuf:in. chmod muuttaa ladatun tiedoston/hakemiston oikeuksia u = user, x = execute.

<img width="1096" height="408" alt="image" src="https://github.com/user-attachments/assets/c8460186-5dc9-4505-a0ff-788e77f4431d" />

Tämä pidetään päällä.

katsotaan tavan selaimella, että kohde löytyy sieltä mistä pitääkin, 127.0.0.2:8000

<img width="696" height="215" alt="image" src="https://github.com/user-attachments/assets/9e2a3bdc-ef09-469c-aca8-592722a39602" />


pistetään netti poikki:

    nmcli networking off


Edellisen kohteen suodatus tapahtui maagisella numerolla 132, ja koska aamuyöllä mennään sieltä mistä aita on matalin, kokeilin sitä ensin:
(common.txt on se tekstilista, mikä ladattiin dirfuz-0 aikana, täältä: https://terokarvinen.com/2023/fuzz-urls-find-hidden-directories/
    
    ffuf -w common.txt -u 127.0.0.2:8000/FUZZ -fs 132

<img width="951" height="171" alt="image" src="https://github.com/user-attachments/assets/c4b0e5e6-c431-444d-ad94-d63806675ecf" />

jne, mahdottoman pitkä lista. Joten tässä kohtaa nuoli ylöspäin ja numero vaihtuu 154:

    ffuf -w common.txt -u 127.0.0.2:8000/FUZZ -fs 154

<img width="1007" height="201" alt="image" src="https://github.com/user-attachments/assets/f4ca68b3-1b14-4061-b9ac-a906f9bbda33" />

netti päälle ja kokeilemaan onnea

    nmcli networking on

saattaa tarvita uuden selainikkunan avaamisen, mutta täältä löytyi! (edelleen motivaatiota etsimässä)
