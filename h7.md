## a) Asenna Hashcat ja testaa sen toiminta murtamalla esimerkkisalasana.

Ensin asennetaan Hashcat ja riippuvaisuudet (wget ja hashid):

    sudo apt-get update
    sudo apt-get -y install hashid hashcat wget

Parametri -y ohittaa "laitetaanko nämä paketit tulemaan". wget on ohjelma, jonka avulla voi ladata tiedostoja komentoriviltä. hashid tunnistaa tiivistefunktion tyypin.

    mkdir hashed
    cd hashed

Ladataan tosi iso salasanalista Rockyou:

    wget https://github.com/danielmiessler/SecLists/raw/master/Passwords/Leaked-Databases/rockyou.txt.tar.gz
    tar xf rockyou.txt.tar.gz
    rm rockyou.txt.tar.gz
